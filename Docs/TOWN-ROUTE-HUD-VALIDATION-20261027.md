# 층간 경로 안내와 HUD 실제 검증 / 階間経路案内とHUD実行検証

開発日: 2026-10-26 経路・HUD実装、2026-10-27 統合・撮影ツール・テストフィクスチャ補完・実行検証。

## 구현 동작 / 実装動作

- 같은 층의 목적지는 기존 NPC·서비스 위치로 안내한다. 다른 층의 목적지는 현재 층에서 들어갈 다음 통로 입구를 초록색으로 표시한다.
- 방향이 있는 통로 그래프에서 전체 경로 길이로 경로를 선택한다. 현재 층, 다음 층, 목적 층과 남은 통로 수를 같은 조회 결과에서 표시한다.
- 연결이 없거나 현재 위치가 통로 내부라 안내할 수 없으면 이전 화살표·진행 문구를 지우고 이유를 표시한다. 역방향 통로나 다른 층의 직접 목적지를 만들어 표시하지 않는다.
- 확장된 미니맵의 이름표 가림 범위는 같은 프레임의 경로 상태를 사용한다. 직접 안내로 돌아오면 기존 미니맵과 이름표 표시가 복원된다.
- 기존 파티 준비 취소·입장 거절·재준비 RPC 관측을 보존하고, 컨트롤러의 경로 조회 메서드만 합본했다. 촬영 드라이버는 별도의 비Shipping 명시 옵션으로만 실행한다.

同じ階では従来のNPC・サービス位置を案内する。別の階では現在階の次の通路入口を緑色で示し、現在・次・目的階と残り通路数を共有結果から表示する。未接続・通路内などで案内できない場合は以前の印と進捗文を消す。拡張ミニマップの名前表示除外と直接案内への復帰も同じフレームの状態に従う。既存の準備取消RPC観測を保ち、撮影は非Shippingの明示オプションに限定する。

온라인 회귀와 HUD 촬영은 별도 실행이다. HUD 촬영은 소유한 임시 논리 카탈로그와 카메라를 사용하는 단독 프로세스를 해상도별로 순차 실행한다. 파일 생성 성공과 화면 검토를 구분했으며 원본 PNG 8장을 직접 확인했다. 1280×800의 고정 HUD 문자 픽셀도 별도 비교해 동일한 문자 마스크를 확인했다. PNG를 편집하거나 다시 인코딩하지 않았다.

オンライン回帰とHUD撮影は別実行である。HUDは所有する一時論理カタログとカメラを使う単独プロセスを解像度ごとに順次実行し、元PNG8枚を直接確認した。固定HUD文字の画素比較も行い、画像編集・再エンコードは行っていない。

독립 감사의 최초 옵션명 오타와 결과 JSON 끝줄 정리 전후의 해시 시점 차이는 원본 실패를 보존하고 별도 감사 보정 기록으로 추적한다. 정확한 정리 전후 바이트와 해시를 대조하며, JSON 의미 비교로 바이트 검증을 대신하지 않는다.

## 검증 한계와 보존 / 検証の限界と保持

- 새 마을 4개의 실제 지형 활성화·층 사이 물리 이동은 이번 검증에 포함되지 않는다. 통로 내부에서는 안내가 재개될 층에 관한 설명을 제공하며 연속 이동 안내를 주장하지 않는다.
- 서버는 Editor 전용 서버다. 독립 cooked Server Target, Linux, 외부망 또는 다른 PC 사이 연결 검증으로 확대하지 않는다.
- 900×600 최초 두 캡처는 초기 배경 표시가 끝나기 전 파란 배경이다. HUD 표시 검증과 전체 월드 표현 품질을 구분한다. 1280×800 네 캡처에는 숲 배경이 표시된다.
- 검증 프로세스는 종료했고 전용 예약 작업은 없다. 자체 DB는 중지하고 볼륨·네트워크와 필수 패키지·증거는 보존한다. 기록되지 않은 Native 프로세스 PID를 관측했다고 주장하지 않는다.
- Git에는 필요한 소스·설정·문서·원본/런타임 에셋만 포함한다. Binaries, Intermediate, Saved, Builds, DDC, 로그, PNG 검증 산출물, DB 데이터와 자격 증명은 제외한다. 원본 메시 OBJ는 빌드 OBJ와 구분해 보존한다.
- 데스크톱 검증 결과와 GitHub CI 상태는 구분한다. CI가 설정되지 않은 저장소의 검사 0개를 CI 통과로 표현하지 않는다.

新規4村の実地形・物理的な階間移動、独立cookedサーバー、Linux、外部ネットワーク・別PC接続は未検証。900×600初期2枚の青い背景はHUD検証とは別の初期表示上の制限である。検証プロセス終了とDB停止後も必要な証拠・パッケージ・データを保持し、Gitには必要ソースと原本／実行アセットのみ含める。ビルド・ログ・検証PNG・DB・資格情報は含めず、デスクトップ実行とGitHub CIを混同しない。
